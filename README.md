# Scikit-Learn-ML-Models

A beginner-friendly machine learning project demonstrating **supervised learning** using Python and Scikit-learn. The project implements regression and classification algorithms, trains models on real datasets, evaluates their performance using standard metrics, and compares classification models.

## 📌 Project Overview

This project focuses on understanding the complete machine learning workflow:

**Dataset → Data Preparation → Model Training → Prediction → Evaluation → Performance Comparison**

The project includes both **classification** and **regression** models using datasets provided by Scikit-learn.

## 🎯 Objectives

* Understand supervised machine learning.
* Implement classification algorithms using Scikit-learn.
* Implement regression algorithms using Scikit-learn.
* Learn how to split data into training and testing sets.
* Apply feature scaling where required.
* Train models and generate predictions.
* Evaluate models using appropriate performance metrics.
* Compare the performance of multiple machine learning models.
* Visualize model performance.

## 🤖 Machine Learning Models

### Classification

The project implements:

* Logistic Regression
* Decision Tree Classifier
* Random Forest Classifier
* K-Nearest Neighbors (KNN)

### Regression

The project implements:

* Linear Regression

## 📊 Datasets

### 1. Breast Cancer Dataset

Used for the classification models.

* Source: Scikit-learn built-in dataset
* Samples: 569
* Features: 30
* Target: Binary classification
* Classes: Malignant and Benign

The dataset is used to train and compare Logistic Regression, Decision Tree, Random Forest, and KNN models.

### 2. Diabetes Dataset

Used for the regression model.

* Source: Scikit-learn built-in dataset
* Samples: 442
* Features: 10
* Target: Continuous numerical value

The dataset is used to demonstrate Linear Regression.

## 📏 Evaluation Metrics

### Classification Metrics

**Accuracy**

Measures the proportion of correctly classified observations.

**Precision**

Measures how many predicted positive cases are actually positive.

**Recall**

Measures how many actual positive cases are correctly identified.

**F1-Score**

Combines precision and recall into a single metric.

### Regression Metrics

**Mean Absolute Error (MAE)**

Measures the average absolute difference between actual and predicted values.

**Mean Squared Error (MSE)**

Measures the average squared difference between actual and predicted values.

**R² Score**

Measures how well the regression model explains variation in the target variable.
